# 🐍 스네이크 게임 (Snake Game)

HTML, CSS, JavaScript로 만든 클래식 스네이크 게임입니다.

## 🎮 게임 플레이

[여기서 게임하기](https://kimhongsoon-learnmore.github.io/School_App01/)

## 🎯 게임 방법

- ⬆️ ⬇️ ⬅️ ➡️ 방향키를 사용하여 뱀을 움직이세요
- 🍎 사과를 먹으면 점수가 올라갑니다
- ⚠️ 벽이나 자기 몸에 부딪히면 게임이 끝납니다
- 점수가 올라갈수록 게임 속도가 빨라집니다

## ✨ 특징

- 반응형 디자인
- 최고 점수 저장 (localStorage 사용)
- 일시정지 기능
- 아름다운 그라디언트 UI
- 모바일 친화적

## 🚀 GitHub Pages 설정 방법

1. GitHub 저장소 설정으로 이동
2. 왼쪽 메뉴에서 "Pages" 선택
3. "Source"에서 브랜치 선택 (main 또는 master)
4. "Save" 클릭
5. 몇 분 후 `https://<username>.github.io/<repository-name>/` 에서 게임을 플레이할 수 있습니다

## 🛠️ 기술 스택

- HTML5 Canvas
- CSS3 (Gradient, Flexbox)
- Vanilla JavaScript (ES6+)

## 📂 파일 구조

```
/
├── index.html    # 메인 HTML 파일
├── style.css     # 스타일시트
├── script.js     # 게임 로직
└── README.md     # 프로젝트 설명
```

## 📱 로컬에서 실행하기

1. 저장소를 클론합니다:
```bash
git clone https://github.com/KimHongsoon-learnmore/School_App01.git
```

2. `index.html` 파일을 브라우저에서 열거나, 로컬 서버를 실행합니다:
```bash
# Python 3
python -m http.server 8000

# Node.js (http-server 사용)
npx http-server
```

3. 브라우저에서 `http://localhost:8000` 접속

## 🎨 스크린샷

게임이 시작되면 방향키로 뱀을 움직여 사과를 먹으세요!
